# CareCompanion

A simple, elderly-friendly app that helps seniors manage their medications and stay safe.

## Features (Frontend)

- Large buttons and clean UI for elderly users
  
- Medication tracking with time reminders
  
- Emergency SOS button
  
- Works as a PWA

## What's Ready
- All screens: Login, Signup, Main Dashboard, Add Medication
  
- Navigation between screens
  
- SOS button (UI only)
  
- Medication list (UI only)

## What's Next (Backend Integration)

- Firebase Authentication (login/signup)
  
- Firebase Firestore (save/load medications)
  
- SMS for SOS and reminders
  
- Scheduling logic (cron jobs for reminders)

## How to Run
1. Clone this repo
2. Open `index.html` in your browser
3. For the full experience, run it as a PWA (use Chrome DevTools → Application → Manifest to test)
